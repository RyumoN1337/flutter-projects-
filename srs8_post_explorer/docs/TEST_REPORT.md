# Отчёт проверки SRS 8

Дата: 29 октября 2026. ОС: Windows. Dart 3.13.3. Проверенная целевая платформа: Web (release).

## Автоматические проверки

`flutter analyze`: No issues found.

`flutter test --reporter expanded`: 14 / 14, All tests passed. Тесты работают без реального интернета через http_mock_adapter и тестовое хранилище SharedPreferences.

1. JSON → Post.
2. Post → JSON.
3. User с вложенным nullable Address.
4. Загрузка страницы через настоящий сгенерированный Retrofit и репозиторий.
5. HTTP 500 преобразуется в серверную ошибку.
6. Отсутствующее обязательное JSON-поле преобразуется в понятную ошибку.
7. Поиск по заголовку и сортировка ID.
8. Фильтр автора передаёт userId в API.
9. Параллельные запросы следующей страницы блокируются, пересекающиеся ID не дублируются.
10. Поздний ответ старого фильтра не меняет текущую ленту.
11. Неудачное обновление сохраняет постоянный кэш.
12. POST возвращает объект, помечает его локальным и сохраняет.
13. Некорректные данные отклоняются до POST.
14. Таймаут, отсутствие соединения и HTTP 4xx различаются.

Стектрейсы в test-output.txt для 500, 503 и некорректного JSON ожидаемы: это debug-логи намеренно вызванных ошибок, а не падения тестов.

`flutter build web`: успешно. Сгенерированные модели и Retrofit получены через `dart run build_runner build`.
